# Ayushman Shukla — Portfolio

Dark cyberpunk portfolio built with Vite, React, TypeScript, Tailwind CSS, Framer Motion, and tsparticles.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Resume

Place your PDF at `public/resume.pdf`. Download buttons already link to `/resume.pdf`.
